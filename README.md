## 🌍 Overview

DonActor is a UX concept project designed to improve the experience of clothing donations by connecting donors, intermediaries, and beneficiary individuals or institutions through a structured digital flow.

The project explored how user-centered design and clear information architecture could help reduce friction and improve coordination in donation processes.

The app was developed for a fictional non-profit organization called *WorldCitizen*.

<br/>

## 🧠 UX Process

The project followed the five Design Thinking stages:

- Empathize
- Define
- Ideate
- Prototype
- Test

The UX/UI, branding, naming, and visual identity were designed within a four-week development cycle.

<br/>

## 🎯 Design Considerations

- Role-based experience for different user groups
- Color-coded navigation and interaction flows
- Simplified donation coordination
- Accessibility and clarity in user communication
- User flows focused on reducing friction during donation processes
